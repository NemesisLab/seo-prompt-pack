📱 Instagram & TikTok Prompts

Prompt #1: Viral Hook Generator

Use this when: You need an attention-grabbing first line for Reels/TikToks

"Generate 10 viral hook ideas for a [PLATFORM: Instagram Reel/TikTok] about [TOPIC]. Each hook should: - Start with a pattern interrupt (shocking statement, question, or bold claim) - Be under 8 words - Create curiosity or FOMO - Appeal to [TARGET AUDIENCE] Format: Numbered list with a brief explanation of why each hook works."
Example Output:
1. "Stop scrolling. This changed everything." → Creates urgency + curiosity
2. "Nobody talks about this..." → Implies secret knowledge

Prompt #2: Reel/Short Script Writer (30-60 seconds)

Use this when: You need a complete video script

"Write a 45-second [Instagram Reel/TikTok/YouTube Short] script about [TOPIC] for [TARGET AUDIENCE]. Structure: - Hook (0-3s): Attention-grabbing opening - Problem (3-10s): What pain point does this solve? - Solution (10-40s): 3 quick tips or steps - CTA (40-45s): What should they do next? Tone: [casual/professional/funny/inspirational] Include suggested on-screen text overlays in [brackets]."

Prompt #3: Carousel Post Creator

Use this when: You want to create educational "swipe-through" posts

"Create a 10-slide Instagram carousel about [TOPIC] that teaches [TARGET AUDIENCE] how to [GOAL]. For each slide, provide: - Slide Title (max 6 words, bold/eye-catching) - Body Text (2-3 short sentences, easy to read on mobile) - Visual Suggestion (what image/graphic to use) Slide 1 must be a hook that makes people want to swipe. Slide 10 must include a clear CTA."

🐦 Twitter/X Prompts

Prompt #4: Viral Thread Builder

Use this when: You want to turn any idea into a high-engagement thread

"Turn this idea into a viral Twitter/X thread: [YOUR IDEA/TOPIC] Requirements: - 8-12 tweets total - Tweet 1: Hook that promises value (e.g., '10 things I wish I knew about...') - Tweets 2-10: Numbered insights, each with a mini-story or example - Tweet 11: Summary + CTA - Use line breaks for readability - Include 2-3 strategic emoji per tweet (not excessive) Optimize for retweets and bookmarks."

Prompt #5: Engagement Reply Generator

Use this when: You want to boost your replies to get noticed

"I want to reply to this tweet: '[PASTE TWEET]' Generate 5 different reply options that: - Add value (insight, joke, or helpful tip) - Are 1-2 sentences max - Increase the chance of the original poster engaging back - Don't sound spammy or self-promotional Tone: [witty/supportive/thought-provoking]"

🎯 Cross-Platform Prompts

Prompt #6: Content Repurposing Machine

Use this when: You want to turn one piece of content into 10+

"I have this content: [PASTE BLOG POST/VIDEO TRANSCRIPT/PODCAST NOTES] Repurpose it into: 1. A Twitter/X thread (10 tweets) 2. 3 Instagram carousel topics (just the titles) 3. 5 LinkedIn post ideas 4. 3 TikTok/Reel hooks 5. 1 email subject line + preview text Keep the core message but adapt the tone for each platform."
💡 Time-Saver: This single prompt can save you 5+ hours per week. Create once, distribute everywhere!

Prompt #7: Storytelling Post Formula

Use this when: You want to share a personal story that resonates

"Help me write a storytelling post about [EXPERIENCE/LESSON LEARNED] for [PLATFORM]. Use this structure: - Hook: Start in the middle of the action or with a bold statement - Setup: Briefly set the scene (who, what, when, where) - Conflict: What went wrong or what challenge did you face? - Resolution: How did you overcome it? - Lesson: What's the takeaway for the reader? - CTA: Ask a question to spark comments Tone: Vulnerable but inspiring. Max 200 words."

💬 Engagement Boosters

Prompt #8: Comment Magnet Questions

Use this when: You need more comments on your posts

"Generate 15 engaging questions I can ask my audience about [TOPIC/NICHE]. Requirements: - Easy to answer (no essay required) - Sparks debate or personal sharing - Mix of 'This or That', 'Fill in the Blank', and open-ended - Avoids yes/no questions Example: 'What's one [TOPIC] myth you used to believe?'"

Prompt #9: Trend Jacker

Use this when: You want to ride a trending topic

"The current trending topic is: [TRENDING HASHTAG/NEWS/MEME] Help me create a post that: - Ties this trend to my niche: [YOUR NICHE] - Feels authentic (not forced) - Adds value or humor - Uses the trending hashtag naturally Platform: [Instagram/Twitter/TikTok] Format: [Post/Thread/Video Script]"

🎁 BONUS: The Viral Formula

Every Viral Post Has 3 Elements:

1
Hook (Pattern Interrupt)
First 3 seconds/words must stop the scroll. Use shock, curiosity, or bold claims.
2
Value (Teach, Entertain, or Inspire)
Deliver on your hook's promise. Give them something worth sharing.
3
CTA (Clear Next Step)
Tell them what to do: comment, share, follow, save, or click.
✅ Real Example:
Hook: "I grew from 0 to 50K followers in 90 days. Here's how:"
Value: [Share 5 specific tactics]
CTA: "Which tactic will you try first? Comment below!"

Advanced Tips

  • Post Timing: Instagram/TikTok: 7-9 AM, 12-1 PM, 7-9 PM. Twitter/X: 8-10 AM, 12-1 PM.
  • Consistency > Perfection: Post 3-5x/week minimum. Algorithm rewards consistency.
  • Engage First: Spend 15 minutes engaging with others before posting your content.
  • Analyze & Iterate: Check your analytics weekly. Double down on what works.
